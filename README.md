# پورتفولیو صداقتی — طراح گرافیک سه‌بعدی

سایت کامل پورتفولیو با HTML / CSS / JavaScript و Three.js

## ویژگی‌ها

- **تم‌های رنگی**: سفید شیری، کرمی، خاکی، کاهگلی، شنی
- **حالت روز / شب**
- **دوزبانه** (فارسی / انگلیسی)
- **نوار شیشه‌ای** (Glassmorphism)
- **بافت کرافت** روی پس‌زمینه (~۳۰٪)
- **متن سه‌بعدی تعاملی** در هیرو (حرکت با موس + محو با اسکرول)
- **سیستم مدار** دور پروفایل (۴ مدار: 3D, 2D, لوگو، پوستر)
- **نمایشگاه سه‌بعدی تعاملی**: پارک، میدان، مکان عمومی
- **صفحات نمونه‌کار** جداگانه
- **فرم تماس** و رزومه

## اجرا

فقط فایل `index.html` را در مرورگر باز کنید (یا با یک سرور محلی):

```bash
cd sadeghati-portfolio
npx serve .
# یا
python -m http.server 8080
```

## تصویر پروفایل

فایل `assets/profile.jpg` را با عکس واقعی جایگزین کنید. در صورت نبودن، یک آواتار پیش‌فرض بارگذاری می‌شود.
